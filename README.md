# CGMD-of-MIN
Ring Sliding-Bond Scission Interplay Affects Toughening in Mechanically Interlocked Networks

Here, we present three cases of CGMD simulations of Mechanically Interlocked Networks and the corresponding control system, i.e., fixed-ring control and no-ring control.

In each directory, you can run a LAMMPS simulation with "lmp -in in"
